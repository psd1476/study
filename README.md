# 『산업표준화법 하위법령』 설명회 및 공청회 — 안내·사전신청 페이지 (임시)

국가기술표준원 『산업표준화법 하위법령』 설명회(2026.11.9~11.11) 및 공청회(2026.11.12) 개최 안내와
권역별 사전신청 접수 연결을 위한 **임시 정적 페이지**입니다. 서버·빌드 과정 없이 파일만 올리면 동작합니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 안내 내용(일시·장소, 대상, 주요내용·프로그램, 사전신청) |
| `assets/style.css` | 디자인 (색상은 파일 맨 위 `:root` 변수) |
| `assets/config.js` | **접수 링크 입력** · 문의처(선택) |
| `assets/app.js` | 접수 링크 연결 · 안내 메시지 동작 |

## 접수폼 주소 넣는 방법

접수폼 주소가 확정되면 `assets/config.js`의 따옴표 안에 주소만 붙여 넣으면 됩니다.

```js
links: {
  gwangju:  "https://...",  // 설명회 · 광주·전라 (11.9 월)
  daejeon:  "https://...",  // 설명회 · 충남·대전 (11.10 화)
  busan:    "https://...",  // 설명회 · 부산·경남 (11.11 수)
  gyeonggi: "https://..."   // 공청회 · 경기 (11.12 목)
},
contact: "문의: 국가기술표준원 산업표준혁신과 000-000-0000"   // 선택 (비우면 표시 안 함)
```

- 주소를 넣은 권역의 [사전신청] 버튼은 접수폼을 **새 창**으로 엽니다.
- 주소를 비워 둔 버튼은 클릭 시 "사전신청 접수 링크는 추후 안내할 예정입니다" 메시지가 표시됩니다.
- 보안상 `https://` 로 시작하는 주소만 연결됩니다. `https://` 로 시작하지 않거나 형식이 잘못된 주소는 무시되고 브라우저 콘솔(F12)에 경고가 표시됩니다.

## 미리보기 / 배포

- 미리보기: `index.html`을 브라우저로 열면 됩니다.
- 배포: `index.html`과 `assets/` 폴더만 웹서버(또는 GitHub Pages 등 정적 호스팅)에 올립니다. (`.git`, `README.md`는 올리지 않습니다.)
- `config.js`를 수정해 다시 올린 뒤에도 캐시 때문에 한동안(GitHub Pages는 약 10분, 일반 서버는 설정에 따라 더 길게) 이전 내용이 보일 수 있습니다. 운영자는 Ctrl+F5로 확인하고, 일반 서버는 html·js 파일에 `Cache-Control: no-cache` 설정을 권장합니다.

## 내용 수정 시 참고

- 일정·장소·프로그램 문구는 `index.html`에서 직접 수정합니다.
- 국가기술표준원 공식 로고(CI)는 포함하지 않았습니다. 사용 승인된 로고 파일이 있으면 `index.html` 상단 `.brand` 영역에 추가하세요.
